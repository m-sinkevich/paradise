МАЯК ЧЕТЫРЁХ ДОМОВ — автозапуск видео на Windows XP
=====================================================

1. VLC
   Установите VLC 2.2.8 для Windows (последняя версия, работающая на XP):
   https://download.videolan.org/vlc/2.2.8/win32/vlc-2.2.8-win32.exe
   Ставьте в папку по умолчанию: C:\Program Files\VideoLAN\VLC

2. Файлы
   Создайте папку C:\beacon и положите туда:
   - beacon.avi        — видео маяка
   - beacon_start.bat  — запуск

   Двойной щелчок по beacon_start.bat — через ~15 секунд видео
   откроется на весь экран и будет крутиться по кругу.
   Если VLC закроется или упадёт — батник сам запустит его снова.

3. Автозапуск при включении
   Откройте папку
   C:\Documents and Settings\<ваш пользователь>\Главное меню\Программы\Автозагрузка
   Правой кнопкой по beacon_start.bat → Создать ярлык → перетащите ярлык в «Автозагрузку».
   Свойства ярлыка → «Окно»: Свёрнутое в значок (чтобы не мелькало чёрное окно).

4. Вход без пароля
   Пуск → Выполнить → control userpasswords2 → снимите галочку
   «Требовать ввод имени пользователя и пароля» → ОК → введите пароль (или пусто).

5. Чтобы экран не гас
   Панель управления → Экран → Заставка: «Нет».
   Там же → Питание: «Отключение дисплея» — Никогда, «Ждущий режим» — Никогда,
   «Спящий режим» — выключить.

6. Убрать помехи
   - Панель управления → Автоматическое обновление → Отключить.
   - Панель управления → Центр обеспечения безопасности → слева
     «Изменить способ оповещения» → снять все галочки.
   - Первый запуск VLC: если появится окно «Политика конфиденциальности» —
     нажмите «Продолжить» один раз (батник старается его не показывать).

7. Мышь не нужна
   Курсор VLC прячет сам. Видео рассчитано на широкий экран 16:9 (1280×720),
   VLC растянет его на весь монитор.

Как остановить: Alt+Tab на чёрное окно батника → Ctrl+C → «Y»;
затем закройте VLC (или просто Ctrl+Alt+Del → завершить vlc.exe и cmd.exe).
