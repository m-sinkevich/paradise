# Инопланетный терминал — экран «кристаллического архива»

Полноэкранная страница для компьютера в режиме киоска. Показывает только инопланетный текст четырёх записей
и картинки-воспоминания; в каждой записи спрятан QR-код, который читает терминал колонистов:

| Запись | QR |
|---|---|
| 01 · Перед разделением пустоты | T59PHD |
| 02 · Странный свидетель | RXYKYG |
| 03 · Ожидание каравана | A99GZW |
| 04 · Запоздалый караван и Обратный Протокол | 9SUJHW |

Работает без интернета: вся папка `alien/` самодостаточна (открывать `index.html`).

## Настройки (в адресе страницы)

- `view=` — `archive` (кристаллический архив), `cradle` (колыбель Каменного Сна), `beacon` (маяк Четырёх Домов);
- `script=` — `piqad` (клингонское письмо из документа), `crystal` (кристаллические знаки);
- `qr=` — `pulse` (QR собирается из знаков раз в запись и держится ~18 с), `mask` (QR всегда виден как печать записи);
- `rec=2` — начать со второй записи.

По умолчанию: маяк Четырёх Домов, кристаллические знаки, QR при резонансе (`view=beacon&script=crystal&qr=pulse`).

Воспоминания по записям: 01 — пещера и силуэт Оболочки Касания; 02 — свидетель; 03 — вершины и звёздная карта
Бетельгейзе → точка Сигма (четыре траектории Стражей); 04 — схема колыбели (гребни, инфузионный клапан,
приёмный кристалл, контроллер) и снова Оболочка.

Пример: `index.html?view=beacon&script=crystal&qr=mask`

Меню мастера: клавиша **M** (или 5 касаний в левом верхнем углу). Там же — следующая запись, «показать QR сейчас»
и готовый адрес для автозапуска. Быстро: **1/2/3** — вид, **S** — письмо, **Q** — режим QR, **N** — следующая запись.

## Автозапуск

- Windows: `kiosk/start-windows.bat` — ярлык на него положить в папку автозагрузки (Win+R → `shell:startup`).
- Linux / Raspberry Pi: `kiosk/alien-terminal.desktop` → `~/.config/autostart/` (поправить путь).

Пересборка после правок шаблона: `python src/build.py`.
