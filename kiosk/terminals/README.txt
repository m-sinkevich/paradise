ТЕРМИНАЛЫ МОДУЛЕЙ В РЕЖИМЕ КИОСКА
=================================

Страница терминала открывается на весь экран, без адресной строки, вкладок и кнопки «закрыть».
Ноутбук не засыпает и не гасит экран.

WINDOWS (папка windows)
  Terminal_PARADISE.bat, Terminal_PIRVELI.bat, Terminal_FREEDOM.bat, Terminal_REDEMPTION.bat — двойной щелчок.
  Terminal_DRUGOY_MODUL.bat — спросит код модуля.
  Браузер: Google Chrome, если его нет — Microsoft Edge.
  Выйти из киоска: Alt+F4.
  После игры: Vernut_son.bat — вернуть обычный сон и затухание экрана.
  Чтобы терминал сам стартовал при включении: Win+R → shell:startup → положить туда ЯРЛЫК нужного .bat
  (все файлы папки windows должны лежать вместе).

MAC (папка mac)
  Terminal_PARADISE.command и т.д. — двойной щелчок.
  Первый раз macOS может не пустить («неустановленный разработчик»): правый щелчок по файлу → Открыть → Открыть.
  Если файл не запускается: в Терминале  chmod +x ~/Downloads/terminals/mac/*.command ~/Downloads/terminals/mac/_kiosk.sh
  Браузер: Google Chrome в режиме киоска. Без Chrome откроется Safari на весь экран
  (у Safari нет настоящего киоска: верхнее меню появляется, если подвести мышь к краю; лучше поставить Chrome).
  Выйти из киоска: Cmd+Q.
  Mac не засыпает, пока открыт терминал (caffeinate), — после выхода всё как обычно.

ВАЖНО ПРО ОФФЛАЙН
  Киоск использует свой отдельный профиль браузера (на каждый модуль — свой).
  Поэтому «Выгрузить базу» нужно делать ВНУТРИ ОКНА КИОСКА: точка «●» слева внизу → пароль мастера →
  «Выгрузить базу» → «Только оффлайн». База, выгруженная в обычном окне Chrome, киоску не видна.
  Камера для сканирования QR разрешается автоматически.
